# Signy — Landing page

Landing page de **Signy**, une application pour apprendre la langue des signes. Elle présente le projet et ses fonctionnalités.

## Technologies

Vue 3, Tailwind CSS, TypeScript et Vite.

## Lancer le projet

Prérequis : Node.js 22 (≥ 22.18.0) ou ≥ 24.12.0, et npm.

Depuis le dossier `landing_page_signy` :

```sh
npm install
npm run dev
```

Ouvrir l’adresse locale affichée dans le terminal.

## Production

```sh
npm run build
npm run preview
```

Le dossier `dist/` contient la version compilée ; `preview` permet de la tester localement.
